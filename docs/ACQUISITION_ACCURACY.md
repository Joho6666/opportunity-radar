## 业务实证边界

本轮 TikHub 请求 **0**，新增预留 **US$0**；具体官方端点价格未取得，密钥有效性和真实国内响应仍未验证。授权批次仍为累计 **5次 / US$0.50 / 单次US$0.10**，错误占次数、无自动重试、重启跨日不补充。收据是管理员核实记录，不是服务商签名或账单；必须实际读取精确官方报价，不能用通用价格区间或测试收据代替。

免费公开 V2EX 外包 RSS 一次请求取得 **10条**样本，保存原始 XML、采集时间、状态码、SHA256，再解析；全部含独立发布时间。规则预测买方6、服务商3、市场1。这是未人工标注的开发样本，不代表6个客户；没有写入客户数据库或真实漏斗。样本保存在 Git 忽略的 `outputs/v2ex-*`，不提交外部用户正文。

本轮真实人工标签 **0/250**，训练/调参/留出均不足。两条公开漏检已加入开发回归，不能当独立留出评测。旧64条合成 Golden Dataset 保持逐类 P/R/F1=1.0、对角混淆矩阵（buyer16，其余各12），只证明这些固定回归，不能报告生产准确率提升。真实留出指标、事实提取错误率和人工筛选时间均**尚未测量**。

真实人工核实买方/联系/回复/报价/成交新增均 **0**，新增真实收入未知；每条核实线索采集成本无分母，**未知**。本轮不提高50/60/75的业务实证评分。该评分不是模型指标。

## 本地模型

```bash
# repo root，安装可选依赖，基础API容器无需安装这些依赖
uv pip install --python .venv/bin/python -r backend/requirements-classifier.txt
# Inbox逐条核实、修正分类、设置同原帖/转载需求分组，再点击“导出标注”
# 以下命令必须有足够的真实人工标签；不会调用付费AI或上传正文
cd backend
../.venv/bin/python ../scripts/train_local_classifier.py /absolute/labels.json /absolute/new-model-dir
```

固定底座 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`，revision `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`，模型卡Apache-2.0。首次训练下载该公开权重；运行时只从可信本地目录加载，`local_files_only=True`。模型目录包含manifest、源文件digest、冻结分组数据和评测报告，不覆盖已有目录；应存放于 Git 忽略的本机路径，不公开真实训练正文。

上线默认 `LOCAL_CLASSIFIER_MODE=shadow`；`LOCAL_CLASSIFIER_PATH`为空会显示MODEL_MISSING并保留规则。训练目标100、调参50、留出100；同URL、显式需求组和相同文本不可跨集。人工还需合并改写转载的同一需求，不能仅依赖相同文本检测。留出只能作封存验收，不能反复用来调参；失败后继续影子模式，下一版本另收新的独立留出。

激活门槛：真实留出≥100、真实买方和预测买方各≥30、买方Precision≥90%、Recall≥规则基线、无分组泄漏。运行时还会阻断低置信、规则分歧和截断的自动分类；事实和人工核实永远不由模型生成。最长8段（每段126token，重叠32）；超过上限取首尾并标记截断；取消/风险规则扫描完整原文。阈值是验收目标，当前没有达标模型。

SetFit1.1.3已实际完成10条**合成基础设施样本**的训练、保存、本地重新加载与超长文本截断检查，部署门槛为false。该产物位于 `outputs/synthetic-setfit-smoke`，不配置给业务API，不用于宣称准确率。

## 使用报价和跟进

在Inbox查看原文、纠正有效状态/支付/服务判断（需备注），确认后转机会。在Pipeline输入自己的销售时薪、预计工时和可选内部时薪成本，预览三档方案；编辑套餐再重新计算；缺少内部成本显示利润未知，金额是CNY税前估算。

点击保存才新增报价版本，版本内容和原文链接不可覆盖。重复请求返回同版本；基于旧版本保存返回409，刷新后再编辑。旧草案首次修订保留为历史版本0（原保存时间未知）。付款节点总比例必须100%，有效期默认14天可编辑。报价JSON也保留人工编辑入口。

下次跟进输入本机时间，API保存带时区的时间；今日/逾期队列按浏览器日期判断并排除已成交/流失/忽略。跟进记录只能追加，备注、联系、回复、发送报价、到账需由本人记录；发送报价记录需选已保存版本。记录不会自动改状态/到账金额，也没有发送消息的能力。
